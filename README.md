# FitApp - Frontend

React 19 + Vite + Redux Toolkit + Bootstrap.

## Codespaces
1. Code → Codespaces → Create (instala dependencias solo).
2. `cp .env.example .env` y poné en `VITE_API_URL` la URL pública del backend + `/api`.
3. `npm run dev` → pestaña Ports → abrir 5173.

## Vercel
Framework Vite. Variable de entorno: `VITE_API_URL=https://<tu-back>.vercel.app/api`.
